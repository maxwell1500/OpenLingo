# Security Policy

## Supported Versions

This project is maintained on the default branch. Please use the latest commit when reporting issues.

## Reporting a Vulnerability

OpenLingo has no private reporting channel, and none is planned. Suspected
vulnerabilities are reported by opening a public issue in the issue tracker:

    https://github.com/maxwell1500/OpenLingo/issues

Please do not email an individual about a report. If a vulnerability would be
harmful if made public before a fix exists, open the issue anyway and say so in
the title; it will be prioritised.

Reports will be reviewed as soon as possible. If a report is accepted, we will work on a fix.
If it is declined, we will explain why.
