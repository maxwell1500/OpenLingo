How to use this

You do not need to know anything about linguistics. If you can tell whether a sentence sounds like something you would say, you are exactly the person this is for.

On each line

  1. Press the round Play button to hear the line. Press again to stop.
  2. Read the sentence shown next to it. Under it is the reading the app promises — for Japanese the romaji, for Spanish a plain-English way of writing the sounds.
  3. Press one of the four buttons:
  • Sounds correct — you would say it exactly like that.
  • Wrong sound — something is mispronounced. Then say which word in the note box, if you can. That is what a fix needs.
  • Unclear / robotic — you can understand it, but it does not sound like a person talking. This is not the same as wrong, and it matters.
  • Skip — you cannot tell, or you would rather not say.

The two small boxes only appear once you have chosen something, and both are optional.

Slowing down

Subtle mistakes hide in fast speech. Set Speed to 0.5× and tick Repeat each line to hear a line over and over. Then compare it with how you yourself would say it, out loud if that helps.

Comparing against a real voice (optional)

If a reference recording has been supplied for a line, a second button Reference appears next to Play. Press it to hear the reference voice instead, and press it again to go back. The two swap instantly, so you can A/B them as many times as you like.

The reference slot is empty for now. To fill it: record each sentence once, as a native speaker, and save the files as .ogg into references/es/ and references/ja/, using the clip's own file name. Reload this page and the buttons appear by themselves. See references/README.md.

Coming back later

Your answers are saved in this browser as you go, so you can close the page and come back. Only this browser, on this computer — nothing is sent anywhere.

Sending the results back — do this last

Click Export answers. A file called pronunciation-review-<date>.json is saved to your Downloads folder. That file is the deliverable. Send it back to whoever gave you this page and nothing else is needed. If you review on a different computer or browser, use Import answers there first.

Shortcuts

  • Space play or stop the line you are on
  • 1 sounds correct   2 wrong sound   3 unclear   4 skip
  • j / k move down / up the list
  • s switch between the clip and its reference recording
